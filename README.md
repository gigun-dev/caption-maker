# Caption Maker

作品データから A4・3列×6行のキャプション PDF を作る静的 Web アプリです。入力、保存、PDF の作成はブラウザ内で行います。

公開版: https://gigun-dev.github.io/caption-maker/

## 使い方

「作品データ」のセルを編集します。行番号から行の挿入・削除、列見出しから列名の変更・移動・削除ができます。「まとめて追加」では、表の貼り付けや CSV ファイルの読み込みができます。タブ、カンマ、半角・全角スペースなどを自動判定し、必要なら区切り文字を変更できます。読み取った内容を確認してから追加してください。列は現在の表の順番に対応します。CSV に表と一致する列名の見出しがあれば、その名前で対応付けます。

「出力設定」では、キャプションの1行目と2行目に表示する列を選べます。プレビューでは実際の PDF をページごとに確認できます。PDF は A4・倍率100%（実際のサイズ）で印刷し、最初に試し刷りしてください。PDF には Noto Sans JP を埋め込みます。

入力データと列、出力設定はこのブラウザに自動保存されます。旧版の保存データも引き継ぎます。消去や端末移行に備え、CSV を書き出してください。CSV はデータのバックアップで、出力設定は含みません。別の端末で追加した列のデータを戻す場合は、読み込む前に同じ列を作成してください。

## 開発・公開

[Bun](https://bun.sh) で `bun install`、`bun run dev`。`bun test` でテスト、`bun run build` で `dist/` に静的ファイルを生成します。main への push で `gh-pages` ブランチにデプロイされます（GitHub Pages の公開元は `gh-pages` ブランチ）。プルリクエストを開くと、確認用ページ（`/pr-preview/pr-番号/`）の URL がコメントで届きます。別の URL に配置するときは `vite.config.js` の base を変更してください。
